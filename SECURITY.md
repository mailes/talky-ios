# Reporting a security issue

Use GitHub's private vulnerability reporting in this repository's Security tab. Do not post credentials, exploit details, private conversations or account data in a public issue. If private reporting is unavailable, use the contact options on https://talkytalky.im/help.html to request a private reporting channel.

This public repository contains client source. Production signing keys, backend credentials, review accounts and private deployment history are excluded. Security scans can flag public cryptographic test vectors and PEM delimiter parsers; these are reviewed separately from deployment credentials. No scan is a guarantee that a codebase is free of vulnerabilities.
