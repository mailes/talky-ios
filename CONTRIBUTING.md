# Contributing

Please open an issue for substantial product changes before starting a large patch. For bug reports, include a minimal reproduction, device and OS version, and relevant logs with private content removed.

Keep pull requests focused. Use English for source comments and logs, keep localized user-facing text in the localization files, and follow the surrounding code style. Describe what changed and the checks you ran. For visual changes, include actual screenshots or recordings; compilation alone does not verify appearance.

Never commit signing material, service credentials, verification codes, production configuration, personal conversations or generated installation packages. Contributions must preserve the project's GPL licensing basis and existing third-party notices. By submitting a contribution, you offer it under the applicable project license without requiring a separate license agreement.
