This export retains the product source and pinned dependency references, but excludes internal deployment notes, review accounts, signing profiles, private keys and generated build output. Public build examples require developer-provided credentials. Inherited provider credentials used by legacy map-link helpers were removed; unavailable credential-dependent resolution falls back to URL sharing. The original upstream build README is retained as docs/UPSTREAM_BUILDING.md.
